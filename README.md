# LabSecure — Access Verification System

A single-page, responsive front-end demonstration for managing researcher records, access requests, permissions, and activity history.

## Run locally
Open `index.html` in a browser, or use VS Code with the Live Server extension.

## Publish on GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and `README.md` to the root of your GitHub repository. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.

## Important
This is a coursework/demo interface only. It does not connect to real doors, biometric devices, or institutional identity systems. Demo data is stored in your browser's local storage.
